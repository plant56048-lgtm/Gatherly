# Gatherly — GenAI Celebration & Event Planner

Open `index.html` in a browser. It works immediately with a local planning engine, and becomes a Gemini-powered assistant when the user pastes a Gemini API key from Google AI Studio.

Features: budget allocation in INR, practical timeline, vendor responsibility checklist, tailored ideas, printing, and clipboard copy. The Gemini prompt requires concise JSON and explicitly protects an event contingency reserve, accessibility needs, and setup buffers.

For Google AI Studio / virtual prompt code demos, use the **Use Gemini** disclosure in the form, then paste your own API key. Do not hard-code or publish API keys in source control.
